Willkommen bei Python

Python ist eine gut lesbare Programmiersprache, die sich für erste Programmierübungen ebenso eignet wie für Webentwicklung, Automatisierung und Datenanalyse. In diesem Lernpfad baust du die Grundlagen Schritt für Schritt auf.

Dein erstes Programm

Die Funktion print() gibt Text oder Werte in der Konsole aus.

print("Hallo, Welt!")
print(2 + 3)

Der erste Aufruf gibt den Text aus, der zweite berechnet zuerst die Addition und gibt anschließend das Ergebnis aus.

Code ausführen

Du kannst Python-Code zum Beispiel in einer IDE wie Thonny, VS Code oder PyCharm schreiben und ausführen. Für kleine Experimente eignet sich auch die interaktive Python-Konsole. Speichere Programme mit der Endung .py.

# begruessung.py
name = "Alex"
print("Hallo", name)

Kommentare und Einrückung

Kommentare beginnen mit # und erklären den Code, ohne ausgeführt zu werden. Python verwendet Einrückungen, um zusammengehörige Anweisungen in Blöcken zu gruppieren. Gewöhnlich werden vier Leerzeichen pro Ebene verwendet.

# Das ist ein Kommentar
if True:
    print("Dieser Code ist eingerückt.")
Merke: Python-Code wird von oben nach unten ausgeführt. Schreibweisen wie Print statt print sind nicht gleichwertig, denn Python unterscheidet Groß- und Kleinschreibung.

Lernaufgaben

  1. Gib mit print() deinen Namen und einen Satz über dein Lernziel aus.
  2. Lass Python die Rechnung 17 * 4 + 6 ausgeben. Was wird zuerst berechnet?
  3. Schreibe ein Programm mit zwei Kommentaren und einer eingerückten if-Anweisung.
Musterlösung zu Aufgabe 2
print(17 * 4 + 6)  # Ausgabe: 74
