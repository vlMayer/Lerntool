Einstieg und erstes Programm

Willkommen! In diesem Kurs lernst du Python von Grund auf. Ein Programm ist eine Folge von Anweisungen, die der Computer ausführt. Python ist eine Programmiersprache; du schreibst Anweisungen in einer Textdatei und lässt sie von Python ausführen.

Dein erstes Programm

print("Hallo, Python!")

print() ist eine eingebaute Funktion, die etwas auf dem Bildschirm ausgibt. Der Text steht in Anführungszeichen, weil er wörtlich ausgegeben werden soll.

Mehrere Anweisungen

print("Hallo!")
print("Ich lerne Python.")

Die Anweisungen werden von oben nach unten ausgeführt. Text innerhalb von Anführungszeichen nennt man Zeichenkette (String).

Kommentare

# Das ist ein Kommentar: Python führt diese Zeile nicht aus.
print("Kommentare erklären den Code.")

Ein Kommentar beginnt mit #. Nutze Kommentare, um zu erklären, warum etwas passiert – nicht, um offensichtlichen Code Wort für Wort zu wiederholen.

Übung
  1. Gib deinen Namen mit print() aus.
  2. Gib in einer zweiten Zeile aus, was du mit Python bauen möchtest.
  3. Füge darüber einen Kommentar ein.
Lösung ansehen
# Mein erstes kleines Python-Programm
print("Ich heiße Alex.")
print("Ich möchte Python lernen.")

Ersetze Alex durch deinen Namen.

Merke: print() zeigt etwas an; Text muss in Anführungszeichen stehen; Kommentare beginnen mit #.
