Schleifen

Schleifen führen Code mehrfach aus. Eine for-Schleife arbeitet typischerweise Elemente einer Folge ab; eine while-Schleife wiederholt sich, solange eine Bedingung wahr ist.

for und range()

for zahl in range(1, 6):
    print(zahl)

range(1, 6) erzeugt die Werte 1 bis 5: Der Startwert zählt mit, die obere Grenze nicht.

Über eine Folge iterieren

farben = ["blau", "grün", "rot"]
for farbe in farben:
    print(f"Farbe: {farbe}")

while-Schleife

rest = 3
while rest > 0:
    print(rest)
    rest -= 1
print("Los!")

Verändere innerhalb einer while-Schleife die Bedingung, damit sie irgendwann endet. Sonst entsteht eine Endlosschleife.

Mit break kann eine Schleife vorzeitig beendet werden; continue springt direkt zum nächsten Durchlauf. Nutze beides sparsam und so, dass der Ablauf verständlich bleibt.

Merke: Prüfe bei Schleifen Startwert, Abbruchbedingung und Veränderung der Laufvariable. Ein kurzer Trockenlauf auf Papier hilft, Off-by-one-Fehler zu finden.

Lernaufgaben

  1. Gib mit einer for-Schleife die Zahlen von 1 bis 10 aus.
  2. Berechne die Summe der Zahlen von 1 bis 100.
  3. Frage so lange nach einem Passwort, bis die Eingabe geheim lautet.
Musterlösung zu Aufgabe 2
summe = 0
for zahl in range(1, 101):
    summe += zahl
print(summe)  # 5050
