Variablen und Datentypen

Eine Variable ist ein benannter Platz, an dem dein Programm einen Wert ablegen kann. Mit = weist du einer Variablen einen Wert zu.

name = "Mira"
alter = 20
print(name)
print(alter)

Häufige Datentypen

  • str: Text, zum Beispiel "Hallo".
  • int: ganze Zahl, zum Beispiel 42.
  • float: Kommazahl, zum Beispiel 3.14 (Python verwendet im Code einen Punkt).
  • bool: Wahrheitswert, entweder True oder False.
preis = 12.5
anzahl = 3
gesamt = preis * anzahl
print(gesamt)  # 37.5
print(type(preis))  # <class 'float'>

Mit type(wert) kannst du den Typ untersuchen. Variablennamen sollten erklären, wofür der Wert steht, etwa gesamtpreis. Namen beginnen üblicherweise mit einem Buchstaben oder Unterstrich und enthalten keine Leerzeichen.

Werte umwandeln

zahl_als_text = "25"
zahl = int(zahl_als_text)
kommazahl = float("2.5")
text = str(zahl)
print(zahl + 5)  # 30

Die Zeichenfolge "25" ist zunächst Text, keine Zahl. Mit int() wird daraus eine ganze Zahl, sofern der Text passend formatiert ist.
