Funktionen: Bausteine für deinen Code

Eine Funktion bündelt eine Aufgabe unter einem Namen. Du definierst sie einmal mit def und kannst sie danach aufrufen.

def begruessung(name):
    print(f"Hallo, {name}!")

begruessung("Alex")
begruessung("Mira")

name ist ein Parameter; beim Aufruf übergibst du ein Argument. Der eingerückte Block gehört zur Funktion.

Ergebnisse zurückgeben

def quadrat(zahl):
    return zahl * zahl

ergebnis = quadrat(5)
print(ergebnis)  # 25

return gibt einen Wert an die aufrufende Stelle zurück. Das ist etwas anderes als print(), das nur eine Ausgabe anzeigt.

Standardwerte und lokale Variablen

def begruessung(name, gruss="Hallo"):
    return f"{gruss}, {name}!"

print(begruessung("Kai"))
print(begruessung("Kai", "Guten Morgen"))

Variablen, die innerhalb einer Funktion angelegt werden, sind normalerweise lokal und von außen nicht direkt sichtbar. Übergib benötigte Werte als Parameter und gib Ergebnisse mit return zurück.

Übung

Schreibe eine Funktion mittelwert(a, b), die den Mittelwert der zwei Zahlen zurückgibt.

Lösung ansehen
def mittelwert(a, b):
    return (a + b) / 2

print(mittelwert(6, 8))  # 7.0
