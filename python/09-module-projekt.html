Module und dein erstes Mini-Projekt

Ein Modul ist eine Datei mit wiederverwendbarem Python-Code. Python bringt viele Module mit. Mit import bindest du sie ein.

import random

geheimzahl = random.randint(1, 5)
print(geheimzahl)

Hier stellt das Modul random unter anderem die Funktion randint() bereit. Für ein kleines eigenes Projekt kombinierst du Variablen, Eingaben, Bedingungen, Schleifen und Funktionen.

Projekt: Mini-Quiz

Das Quiz stellt Fragen, vergleicht die Antworten und zählt die Punkte. Tippe den Code selbst ab und ergänze danach eigene Fragen.

def stelle_frage(frage, loesung):
    antwort = input(frage + " ").strip().lower()
    if antwort == loesung.lower():
        print("Richtig!")
        return 1
    print(f"Noch nicht. Die richtige Antwort ist: {loesung}")
    return 0

fragen = [
    ("Welche Funktion gibt Text aus?", "print"),
    ("Welches Schlüsselwort definiert eine Funktion?", "def"),
    ("Welcher Typ speichert Wahr oder Falsch?", "bool"),
]

punkte = 0
for frage, loesung in fragen:
    punkte += stelle_frage(frage, loesung)

print(f"Du hast {punkte} von {len(fragen)} Punkten.")

Erweiterungen

  • Füge mindestens zwei eigene Fragen hinzu.
  • Zeige am Ende eine Nachricht abhängig von der Punktzahl.
  • Erlaube pro Frage einen zweiten Versuch.
  • Speichere Fragen später in einer Datei und lies sie beim Start ein.
