Lektion 03 von 09

Eingaben und Ausgabe

Mit input() kann dein Programm eine Eingabe von der Person am Computer entgegennehmen. Wichtig: input() liefert immer Text zurück – auch wenn eine Zahl eingegeben wurde.

name = input("Wie heißt du? ")
print("Hallo", name)

Mit Eingaben rechnen

alter_text = input("Wie alt bist du? ")
alter = int(alter_text)
print("Nächstes Jahr bist du", alter + 1)

Wenn die Eingabe eine Kommazahl sein darf, kannst du sie mit float() umwandeln. Ungültige Eingaben können dabei später zu einem Fehler führen; Fehlerbehandlung folgt in Lektion 8.

Formatierte Texte

produkt = "Kaffee"
preis = 3.5
print(f"{produkt} kostet {preis:.2f} Euro.")

Ein f-String beginnt mit f. Variablen kommen in geschweifte Klammern. :.2f zeigt eine Zahl mit zwei Nachkommastellen.

Übung

Frage nach zwei Zahlen, addiere sie und gib das Ergebnis in einem verständlichen Satz aus.

Lösung ansehen
erste_zahl = float(input("Erste Zahl: "))
zweite_zahl = float(input("Zweite Zahl: "))
summe = erste_zahl + zweite_zahl
print(f"Die Summe ist {summe}.")
