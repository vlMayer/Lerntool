Modul 06 · Sammlungen

Datenstrukturen

Listen, Tupel, Dictionaries und Sets speichern mehrere Werte. Die Wahl der Struktur hängt davon ab, ob Reihenfolge, Veränderbarkeit, eindeutige Werte oder Schlüssel-Wert-Zuordnungen gebraucht werden.

Listen

spiele = ["Portal", "Hades", "Celeste"]
spiele.append("Hollow Knight")
print(spiele[0])
print(len(spiele))

Listen sind geordnet und veränderbar. Der erste Index ist 0; negative Indizes zählen vom Ende aus.

Tupel und Sets

koordinate = (50.8, 7.2)  # Tupel: geordnet, unveränderbar
farben = {"rot", "blau", "rot"}  # Set: eindeutige Werte
print(farben)

Dictionaries

person = {"name": "Mira", "alter": 21}
print(person["name"])
person["stadt"] = "Bonn"

Ein Dictionary ordnet jedem Schlüssel einen Wert zu. Schlüssel sind eindeutig; Werte können aktualisiert werden.

Über Sammlungen iterieren

preise = [2.5, 4.0, 3.25]
for preis in preise:
    print(preis)
Auswahlhilfe: Verwende eine Liste für eine veränderbare Reihenfolge, ein Tupel für eine feste Sammlung, ein Set für eindeutige Werte und ein Dictionary für Nachschlagen über Schlüssel.

Lernaufgaben

  1. Erstelle eine Liste mit vier Lieblingsfilmen. Gib das zweite Element aus und ergänze einen fünften Film.
  2. Erzeuge aus einer Liste mit doppelten Zahlen ein Set. Was passiert mit Duplikaten?
  3. Lege ein Dictionary für ein Buch mit Titel, Autor und Erscheinungsjahr an. Ändere das Jahr und gib den Titel aus.
Musterlösung zu Aufgabe 3
buch = {"titel": "Dune", "autor": "Frank Herbert", "jahr": 1965}
buch["jahr"] = 2021
print(buch["titel"])
