Modul 04 · Entscheidungen

Verzweigungen mit if

Mit if, elif und else führt ein Programm abhängig von Bedingungen unterschiedliche Anweisungen aus.

Eine Bedingung

temperatur = 22
if temperatur > 20:
    print("Es ist warm.")

Nach der Bedingung steht ein Doppelpunkt. Der eingerückte Block gehört zur Verzweigung.

Mehrere Fälle

punkte = 78
if punkte >= 90:
    note = "sehr gut"
elif punkte >= 75:
    note = "gut"
else:
    note = "weiter üben"
print(note)

Python prüft die Bedingungen der Reihe nach und führt den ersten passenden Zweig aus. Vergleichsoperatoren sind ==, !=, <, >, <= und >=. Für logische Kombinationen gibt es and, or und not.

alter = 20
hat_ticket = True
if alter >= 18 and hat_ticket:
    print("Zutritt möglich")
Achtung: = weist einen Wert zu; == vergleicht zwei Werte. Die Einrückung legt fest, welcher Code zu welchem Zweig gehört.

Lernaufgaben

  1. Prüfe, ob eine eingegebene Zahl positiv, negativ oder null ist.
  2. Gib abhängig von einer Punktzahl eine passende Kategorie aus: ab 90 „sehr gut“, ab 75 „gut“, sonst „noch üben“.
  3. Prüfe mit einer kombinierten Bedingung, ob eine Zahl zwischen 10 und 20 einschließlich liegt.
Musterlösung zu Aufgabe 3
zahl = int(input("Zahl: "))
if 10 <= zahl <= 20:
    print("liegt im Bereich")
else:
    print("liegt außerhalb")
