Entscheidungen mit if

Mit Bedingungen lässt du dein Programm abhängig von Werten unterschiedliche Wege nehmen. Python wertet die Bedingung als wahr oder falsch aus.

temperatur = 18
if temperatur >= 20:
    print("Es ist warm genug.")
else:
    print("Nimm eine Jacke mit.")

Der Doppelpunkt beginnt den eingerückten Block. Die Einrückung zeigt Python, welche Anweisungen zu welchem Zweig gehören. Verwende innerhalb eines Blocks konsistent vier Leerzeichen.

Mehrere Fälle

punkte = 76
if punkte >= 90:
    note = "sehr gut"
elif punkte >= 70:
    note = "gut"
else:
    note = "weiter üben"
print(note)

Vergleiche und Logik

  • == gleich, != ungleich.
  • <, <=, >, >= vergleichen Zahlen oder passende Werte.
  • and verlangt, dass beide Bedingungen wahr sind; or genügt, wenn mindestens eine wahr ist; not kehrt einen Wahrheitswert um.
alter = 21
hat_ticket = True
if alter >= 18 and hat_ticket:
    print("Einlass möglich")
Übung

Lies ein Alter ein. Gib aus, ob die Person minderjährig oder volljährig ist.

Lösung ansehen
alter = int(input("Wie alt bist du? "))
if alter >= 18:
    print("Volljährig")
else:
    print("Minderjährig")
