Module und Abschlussprojekt

Module teilen Programme in wiederverwendbare Dateien auf. Im Abschlussprojekt verbindest du Variablen, Eingaben, Verzweigungen, Schleifen, Funktionen und Listen zu einem kleinen Quiz.

Ein eigenes Modul

Speichere wiederverwendbare Funktionen in einer Python-Datei. Liegen Modul und Programm im selben Ordner, kann das Programm das Modul importieren.

# datei: rechenhilfe.py
def addiere(a, b):
    return a + b

# datei: main.py
import rechenhilfe
print(rechenhilfe.addiere(3, 4))

Die Datei-Endung .py gehört nicht in den Modulnamen beim Import. Standardbibliotheken wie math und random lassen sich auf dieselbe Weise importieren.

Abschlussprojekt: Mini-Quiz

Erstelle ein Quiz mit mehreren Fragen. Zähle richtige Antworten, gib am Ende die Punktzahl aus und verwende eine Funktion, damit die Frage-Antwort-Prüfung wiederverwendbar ist.

def stelle_frage(frage, antwort):
    eingabe = input(frage + " ").strip().lower()
    return eingabe == antwort.lower()

fragen = [
    ("Welche Funktion gibt Text aus?", "print"),
    ("Wie beginnt ein Kommentar?", "#"),
    ("Welcher Typ speichert ganze Zahlen?", "int"),
]
punkte = 0
for frage, antwort in fragen:
    if stelle_frage(frage, antwort):
        print("Richtig!")
        punkte += 1
    else:
        print("Leider falsch.")
print(f"Ergebnis: {punkte}/{len(fragen)}")

Projekt erweitern

  • Füge Fragen hinzu und akzeptiere mehrere richtige Schreibweisen.
  • Prüfe Eingaben und verhindere, dass ein leeres Quiz zu einem Fehler führt.
  • Speichere Fragen in einer Datei und lade sie beim Programmstart.
  • Teile das Quiz in Module für Fragen, Auswertung und Programmstart auf.
Abschluss: Ein gutes kleines Projekt ist verständlich, testbar und in Funktionen aufgeteilt. Ergänze Kommentare dort, wo sie den Zweck einer Entscheidung erklären.

Lernaufgaben

  1. Schreibe eine Datei rechenhilfe.py mit den Funktionen addiere() und multipliziere(). Importiere das Modul in einem zweiten Skript.
  2. Baue im Quiz eine dritte Antwortmöglichkeit „überspringen“ ein und werte sie gesondert aus.
  3. Ergänze eine Funktion, die abhängig vom Punktestand eine Rückmeldung ausgibt.
  4. Teste dein Programm mit richtigen, falschen und leeren Eingaben. Beschreibe einen gefundenen Fehler und seine Behebung.
Musterlösung zu Aufgabe 3
def rueckmeldung(punkte, anzahl):
    quote = punkte / anzahl if anzahl else 0
    if quote == 1:
        return "Perfekt!"
    elif quote >= 0.5:
        return "Gut gemacht!"
    return "Weiter üben!"
