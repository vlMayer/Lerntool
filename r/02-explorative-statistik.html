Explorative Statistik

Explorative oder deskriptive Statistik beschreibt die vorliegenden Daten. Sie hilft, Verteilungen, typische Werte, Streuung und Zusammenhänge zu erkennen, ohne daraus automatisch auf eine größere Grundgesamtheit zu schließen.

Skalenniveau und Kennzahlen

Die Messskala beeinflusst, welche Zusammenfassung sinnvoll ist. Nominale Merkmale sind Kategorien ohne Rangfolge (z. B. Region); ordinale Merkmale besitzen eine Rangfolge; bei kardinalen Merkmalen sind Abstände interpretierbar (z. B. Preisindex).

  • Nominal: Häufigkeiten und Modus.
  • Ordinal: Median und Quantile.
  • Kardinal: Mittelwert, Median und Streuungsmaße wie Standardabweichung.

Ein Mittelwert für eine Kategorie ohne sinnvolle Zahlenabstände ist nicht aussagekräftig. Bei schiefen Verteilungen oder Ausreißern ist der Median oft robuster als der Mittelwert.

Zusammenfassungen in R

Das Vorlesungsbeispiel verwendet studenten mit der kardinalen Variable regionaler_preisindex_2022. Die folgenden Befehle setzen voraus, dass der Datensatz bereits eingelesen wurde.

summary(studenten$regionaler_preisindex_2022)
mean(studenten$regionaler_preisindex_2022, na.rm = TRUE)
median(studenten$regionaler_preisindex_2022, na.rm = TRUE)
sd(studenten$regionaler_preisindex_2022, na.rm = TRUE)

# Mit mosaic-Syntax wie in den Vorlesungsfolien
mosaic::favstats(~ regionaler_preisindex_2022, data = studenten)

favstats() liefert unter anderem Minimum, Quartile, Median, Maximum, Mittelwert, Standardabweichung sowie die Zahl fehlender Werte. na.rm = TRUE weist viele Basisfunktionen an, fehlende Werte bei der Berechnung auszulassen.

Streuung und Korrelation

Die Standardabweichung beschreibt die typische Entfernung von Werten zum Mittelwert. Die Tschebyschow-Ungleichung liefert eine allgemeine Untergrenze für den Anteil der Beobachtungen innerhalb mehrerer Standardabweichungen, gilt aber nicht als exakte Prozentregel für einen konkreten Datensatz.

x <- studenten$regionaler_preisindex_2022
mean(x, na.rm = TRUE) - sd(x, na.rm = TRUE)
mean(x, na.rm = TRUE) + sd(x, na.rm = TRUE)

# Lineare Korrelation zweier numerischer Variablen
cor(studenten$regionaler_preisindex_2022,
    studenten$gesamt,
    use = "complete.obs")

Eine Korrelation nahe 1 zeigt einen positiven linearen Zusammenhang, nahe −1 einen negativen und nahe 0 keinen oder nur einen schwachen linearen Zusammenhang. Korrelation allein belegt keine Ursache-Wirkungs-Beziehung; auch Ausreißer und nichtlineare Muster können die Interpretation beeinflussen.

Lineare Regression

Ein einfaches lineares Modell beschreibt den Zusammenhang einer Zielvariable y mit einer erklärenden Variable x. Die Koeffizienten werden mit lm() geschätzt.

modell <- lm(regionaler_preisindex_2022 ~ gesamt, data = studenten)
summary(modell)
plot(modell)

Der Achsenabschnitt ist der modellierte Wert von y, wenn x = 0; der Steigungskoeffizient beschreibt die erwartete Änderung von y pro zusätzlicher Einheit von x. Das Bestimmtheitsmaß R-squared beschreibt den Anteil der beobachteten Streuung, den das Modell in der Stichprobe erklärt, nicht die Kausalität.

Wichtig: Eine deskriptive Kennzahl fasst die beobachtete Stichprobe zusammen. Inferenzstatistik behandelt zusätzlich die Unsicherheit beim Schluss auf eine Grundgesamtheit.

Lernaufgaben

  1. Berechne für den Preisindex Minimum, Median, Mittelwert und Standardabweichung. Vergleiche Mittelwert und Median: Gibt es Hinweise auf eine Schiefe oder Ausreißer?
  2. Berechne mit favstats() die Quartile. Formuliere in eigenen Worten, was das erste Quartil bedeutet.
  3. Berechne die Korrelation zwischen Preisindex und Studierendenzahl. Nenne Richtung und Stärke des linearen Zusammenhangs und einen Grund, weshalb daraus keine Kausalität folgt.
  4. Schätze lm(regionaler_preisindex_2022 ~ gesamt, data = studenten). Interpretiere die Steigung und das R-squared in einem Satz.
Hinweis zu Aufgabe 2

Das erste Quartil ist der Wert, unter dem ungefähr 25 % der beobachteten Werte liegen (bei üblichen Quantilsdefinitionen).
