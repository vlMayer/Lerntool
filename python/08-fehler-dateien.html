Fehler behandeln und Dateien lesen

Fehlermeldungen helfen, Probleme zu finden. Häufige Ursachen sind Tippfehler, falsche Datentypen oder ein Zugriff auf etwas, das nicht existiert. Lies bei einer Fehlermeldung den Typ und die letzte Zeile zuerst.

try und except

eingabe = input("Gib eine ganze Zahl ein: ")
try:
    zahl = int(eingabe)
except ValueError:
    print("Das war keine gültige ganze Zahl.")
else:
    print(f"Du hast {zahl} eingegeben.")

Der Code im try-Block wird versucht. Wenn genau der erwartete Fehler ValueError auftritt, läuft der passende except-Block. Vermeide ein pauschales Abfangen aller Fehler, wenn du nicht weißt, wie du damit umgehen sollst.

Dateien mit with öffnen

Mit with wird eine Datei nach der Nutzung zuverlässig geschlossen. Der Dateipfad ist relativ zum Arbeitsverzeichnis des Programms.

# Textdatei schreiben
with open("notiz.txt", "w", encoding="utf-8") as datei:
    datei.write("Python üben macht Spaß.\n")

# Datei lesen
with open("notiz.txt", "r", encoding="utf-8") as datei:
    inhalt = datei.read()
    print(inhalt)

Der Modus "w" schreibt neu und überschreibt eine vorhandene Datei; "r" liest. Nutze encoding="utf-8" für Texte mit Umlauten.

Übung

Frage eine Zahl ab und gib ihr Quadrat aus. Wenn die Eingabe keine ganze Zahl ist, zeige eine verständliche Meldung.

Lösung ansehen
try:
    zahl = int(input("Zahl: "))
    print(f"Quadrat: {zahl ** 2}")
except ValueError:
    print("Bitte gib eine ganze Zahl ein.")
