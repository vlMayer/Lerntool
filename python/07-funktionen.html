Modul 07 · Wiederverwendung

Funktionen

Funktionen bündeln wiederverwendbare Anweisungen unter einem Namen. Sie helfen, Programme in kleine, verständliche Aufgaben aufzuteilen.

Funktion definieren und aufrufen

def begruessung():
    print("Hallo!")

begruessung()

Der eingerückte Block ist der Funktionskörper. Die Definition allein führt ihn noch nicht aus; dazu braucht es den Aufruf.

Parameter und Rückgabewerte

def quadrat(zahl):
    return zahl * zahl

ergebnis = quadrat(5)
print(ergebnis)

Parameter sind Eingaben in die Funktion. return gibt ein Ergebnis an den Aufrufer zurück. Das ist etwas anderes als print(), das lediglich Text ausgibt.

Standardwerte und mehrere Parameter

def brutto(netto, steuersatz=0.19):
    return netto * (1 + steuersatz)

print(brutto(100))
print(brutto(100, 0.07))

Ein Parameter mit Standardwert kann beim Aufruf weggelassen werden. Pflichtparameter stehen vor Parametern mit Standardwert.

Gute Funktionen: Erledigen eine klar umrissene Aufgabe, verwenden aussagekräftige Namen und liefern bei Berechnungen einen Rückgabewert statt nur etwas auszugeben.

Lernaufgaben

  1. Schreibe eine Funktion verdoppeln(zahl), die das Doppelte zurückgibt.
  2. Schreibe eine Funktion, die zwei Zahlen annimmt und die größere zurückgibt.
  3. Schreibe eine Funktion preis_mit_rabatt(preis, prozent), die den reduzierten Preis zurückgibt, und teste sie mit 20 % Rabatt.
Musterlösung zu Aufgabe 1
def verdoppeln(zahl):
    return zahl * 2

print(verdoppeln(7))  # 14
